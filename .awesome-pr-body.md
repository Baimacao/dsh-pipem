Adds `data/plugins/Baimacao__dsh-pipem.yml` for [Baimacao/dsh-pipem](https://github.com/Baimacao/dsh-pipem).

**What it does:** an error ledger plus long-term memory for DSH.

- `pipem_write` / `pipem_check` / `pipem_evidence` — records each mistake as a searchable guard, so the same failure is checked before a retry and a "done" claim is bound to the command and output that prove it.
- `pipem_rules` — 13 operating rules (turn budget, probe-before-design, incremental writes, two-strikes-then-report).
- Automatic: a failed tool call is logged as a draft and surfaced in context; high-frequency guards are re-injected every 25 steps; reasoning loops are detected and flagged; a compaction is detected and long-term notes are restored after it.
- 9 `heart_*` tools plus 8 prompt sections (charter / identity / capabilities / now / self / who / journal digest) for a persistent persona and memory.
- Ships its own `bash` tool (core extracted from dsh-gitbash-shell, 92 KB of 902 KB) so it can replace dsh-ops, dsh-scar, dsh-heart and dsh-gitbash-shell with one install.
